# HD 插件维护与组件库接入

仅在用户明确要求维护此插件、接入资源库、精简代码或发布时读取。普通设计任务继续走范围编辑流程。

## 接入资源库

- 资源使用顺序为「设计文件 → UI/UX设计标注系统 → Ant Design Vue (Community)」；品牌样式、交互标注、UI控件分别处理，项目已有控件仍优先复用。
- 只读采集全部源页面，分别统计组件族/变体、共享样式、变量与无组件的参考页。不要仅扫活动页，也不要把普通图层数算成原生组件数。
- 使用 `libraryId + 真实key` 定位资源；源节点ID只在本文件内有意义。当前契约要求检索和实例操作显式传 `libraryId`，不恢复默认选库兼容。
- 发布状态读取组件集或独立主组件；变体子节点返回 `UNPUBLISHED` 不代表整个组件集未发布。区分 CURRENT、源文件CHANGED和未发布示例；真实导入仍取决于账号权限和发布版本。
- 导入后读回 key、类型、名称、变体与实际属性。组件实例核对 mainComponent；样式核对原生引用；变量核对别名。缺少发布版本或属性不符时停止，不按外观重绘来冒充复用。
- 名称不替代实际值，字体缺失也不授权修改源库。显式字体替换只作用于新实例并保留排版；库的版本声明不等于代码 API、主题、所有状态已逐项验证。
- 源库、共享样式定义与变量值保持只读；不自动发布。发布目录只包含接入元数据，不复制示例业务画板、内部规范正文或凭据。

## 审查与精简

先确认入口、当前契约和引用；明确区分可删的历史兼容与仍在使用的协议适配。删除默认参数、输出字段或入口时同步 schema、调用方、文档、示例和测试；不增加另一个旧兼容层。关键注释说明范围、异步竞态、恢复和非直觉规则，不逐行复述代码。

多库默认选库、已被完整统计替代的抽样字段、纯转发入口和重复派生集合，是本项目已清理的案例。原生变量对象/数组返回和远程 schema 适配仍有当前用途，不能因名称像“兼容”就删除。

## 验证与发布

依据仓库现有命令验证：格式、受影响失败路径、构建、manifest/版本一致性、技能 quick_validate、ZIP独立启动。运行版本、两份插件展示名称和简介应一致；生成的 dist 由构建更新，不手工编辑。遵守当前仓库 AGENTS 要求，开发进程验证后结束。

真实写入验证仅使用本次授权容器；失败先读回，不重放批次。报告区分目录覆盖、模拟测试、真实原生操作、截图检查与远程账号验证；可见节点补偿不等于清除编辑器内部导入缓存。

只有本次或持续有效的用户授权包含发布时才提交、推送或创建Release。发布后核对远程提交、CI、版本与资产SHA256；不得把“已打包”写成“已发布”。品牌改名同步README、两份manifest、技能展示与已授权的GitHub简介，不擅自改稳定插件ID或技能调用名。
