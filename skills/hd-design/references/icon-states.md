# 图标与状态

项目现有组件优先；选择一种单色线性或一种实心图标体系，不混用字形符号、emoji、不同线宽或任意大小。语义相同的操作复用同一图形，完整保留图标名称和快捷键/可访问名称。

图标颜色与按钮状态共用语义 token。以下为未提供品牌 token 时的示例，先核对项目实际规范：

| 状态 | 图形 fill/stroke | 背景 | 边框 |
| --- | --- | --- | --- |
| 默认 | #667085 | #FFFFFF | 透明/项目默认 |
| 悬停 | #245EDB | #F1F5FF | #D6E2FF |
| 按下 | #1848AD | #C9DCFF | #699EFF |
| 选中 | #286BFF | #EAF1FF | #B8D0FF |
| 选中悬停 | #245EDB | #DCE8FF | #8FB5FF |
| 聚焦 | 继承当前状态 | 继承当前状态 | 另加2px外焦点环 |
| 禁用 | #A9B1BF | #F7F8FA | 透明/禁用边框 |

状态优先级：禁用 → 按下 → 选中悬停 → 选中 → 悬停 → 默认。聚焦环独立叠加。鼠标移出：未选中恢复默认，选中保留选中色；更换工具时旧项恢复默认且只有新工具保持选中。按下、聚焦不能改变布局尺寸。普通状态转换100–150ms，减少动态效果时直接切换。

Pixso 复用图标时读取内部 path/rectangle/vector 的 fill/stroke；只改外框颜色不会自动让内部图形变色。保留图标镂空与背景，不要给所有子层硬填同一颜色。优先已有组件状态变体；无变体时在授权子树内制作可编辑状态样例，不能修改共享主组件影响其他页面。真实浏览器实现应让 SVG 描边/填充继承 `currentColor`，并核对 CSS 优先级，尤其选中+悬停+按下组合。

Web 桌面点击区至少24×24 CSS px；常见32px按钮和20px图标是示例，遵循当前项目。同类图标居中、图文间距统一，不能仅靠颜色表达选中，配合边框/背景及状态语义。
