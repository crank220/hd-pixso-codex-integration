# 第一版验证记录

日期：2026-11-26。版本：0.1.0。

## 已完成

- 26项自动化测试通过（Node.js 24.15.0 / macOS）。覆盖范围隔离、旧快照拒绝、字体加载期间的手动改稿、组件主定义保护、混合文字样式快照、失败补偿回滚、确认映射、项目组件优先及 npm/pnpm/Yarn 版本读取。
- 通过真实 MCP SDK stdio 客户端验证工具发现、项目读取和输入校验。写工具不开放任意脚本。
- 官方 Agent Plugins plugin.json / mcp.json schema 验证通过，示例配置验证通过。
- Codex CLI 通过临时配置覆盖发现 hd-pixso-codex@hd-design-plugins；未更改全局 marketplace 设置，也未自动安装到用户插件缓存。
- zip 解压至临时独立目录，在没有 node_modules 的情况下启动，验证10个工具及组件选择。
- `npm run dev` 成功启动 stdio 开发服务器并在检查后停止。
- `npm run doctor` 和 `npm run smoke:live` 连接本机 Pixso Desktop MCP 成功：只读获取连接状态、绑定范围、读取快照；重复读取的 revision 一致。未对真实设计执行写入。
- 技能 quick_validate 验证通过；审阅技能与辅助代码的数据流，没有指示上传设计、读取凭据或越过页面范围。
- npm 运行依赖审计未发现已知漏洞；构建物附12个实际打包依赖的许可文本。

## 独立审查及修复

独立只读审查发现并修复：字体加载期间的并发改稿、裸组件ID绕过映射、项目组件候选优先级、Yarn descriptor 前缀误匹配。相应行为均有测试覆盖。

## 验证边界

- 当前机器实测 Node24，CI配置覆盖 Node20/22/24，但远端 CI 运行结果须以 GitHub Actions 为准。
- 合成画布验证了声明式写入和补偿逻辑；真实 Pixso 写入、复杂自动布局、组件 overrides 和字体行为还需要设计师在获准的测试页面做验收。
- 未将读取公司规范等同于自动通过公司全部规则；几何检查、截图检查、人工交互验收分别负责。
- 第一版提供设计组件与代码组件显式映射，不提供完整双向代码同步。

## 0.1.1 调用名称调整

技能调用名称、目录、默认提示词与安装说明统一为 `hd-design`，新会话使用 `$hd-design`。插件版本升至0.1.1；安装包验证按实际版本查找，不再固定旧版文件名。
