# Codex + Pixso 第一版规格

用户已确认以双窗口协作完成 Web 端可编辑设计。Codex 负责理解需求和检查，Pixso 负责选择页面、查看和手动编辑。

第一版交付为 Codex 插件（技能 + 本地 stdio MCP），上游连接已有 Pixso Desktop MCP（默认 http://127.0.0.1:3667/mcp）。无需另造 Pixso 插件、云服务或模型 API Key。仓库 crank220/hd-pixso-codex-integration。

## 行为

- 读取活动文档、页面、选择、图层、组件及样式；明确绑定目标页面或页面内子树。
- 写入仅接受声明式更新、插入、克隆与组件实例，不开放任意脚本；超出范围、切换文件/页面、手动编辑后使用旧版本写入均拒绝。
- 设计师手动改稿后重新读取最新快照，返回新的 revision；不覆盖尚未读取的变更。
- 所有操作先预校验；写入失败尝试逆向回滚并单独验证，不能将已尝试回滚表述为恢复成功。网络写入超时不重放。
- 复用优先级：项目组件 > Ant Design Vue > 必要时新增。映射记录本地 JSON，先确认映射再实例化；不假装设计组件等同于代码实现。
- 默认 Vue + ant-design-vue ^4.1.0。连接项目只读 package.json、npm/pnpm/yarn 锁文件及组件文件；使用锁文件实际版本核对，不用声明范围冒充安装版本。
- UI 基础按对应版本 Ant Design Vue，明确的公司品牌覆盖优先。公司 UI/UX 标注规范单独读取；缺少规范时报告未验证。
- 规范检查输出文字/内容/状态标注与布局检查证据，不将自动几何检查等同于截图验收。
- 公共仓库不含公司设计、内部文档、真实截图、密钥或绝对个人路径。实际本机设计只用于只读连通检查。

## 第一版边界

不提供完整双向代码生成，不保证任意组件自动识别，不支持视频生成或云端访问本地 Pixso。组件映射以显式配置为准。支持可编辑基础图层与现有组件实例；复杂布局优先克隆项目已有结构。安装后在新会话使用。
